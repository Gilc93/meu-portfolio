# Meu Portfólio

Portfólio pessoal de Gildevan Carlos Pereira dos Santos, feito com React e Vite para um trabalho da faculdade (ADS).

## O que tem na página

- Apresentação com foto e descrição
- Habilidades
- Sobre mim, com abas de interesses e objetivos
- Projetos, com botão para ver os detalhes
- Contato no rodapé

## Tecnologias

- React
- Vite
- CSS
- useState e props

## Como rodar

```
npm install
npm run dev
```
